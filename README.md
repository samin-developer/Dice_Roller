# 🎲 3D Dice Roller

A modern and interactive **3D Dice Roller Web App** that simulates random dice rolls with physics-inspired animations and keeps track of your rolling statistics.

## ✨ Features

- 🎲 Interactive 3D dice
- 🔢 Roll **1 Dice** or **2 Dice**
- 🎯 Random dice results
- 📊 Total number of rolls tracking
- 🧮 Last roll sum
- 🏆 Highest sum tracking
- 👯 Doubles counter
- 🔄 Reset statistics
- ⌨️ Press **Spacebar** to roll the dice
- 🔊 Sound toggle
- 🌙 Modern dark-themed UI
- ✨ Smooth animations and visual effects
- 📱 Responsive design



## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- CSS Animations
- DOM Manipulation
- Random Number Generation

## 🎮 How to Use

1. Open the application in your browser.
2. Select either:
   - **1 Dice** – Roll one die
   - **2 Dice** – Roll two dice
3. Click **Roll Dice** or press the **Spacebar**.
4. View your result and statistics.
5. Continue rolling to track your highest score and doubles.

## 📊 Statistics

The application tracks:

| Statistic | Description |
|-----------|-------------|
| Total Rolls | Number of times the dice have been rolled |
| Last Sum | Sum of the most recent roll |
| Highest Sum | Highest sum achieved |
| Doubles | Number of times both dice show the same number |
